# AgentLean workflow

For substantial repository work, use the AgentLean workflow skill when available.
Locate relevant sources before reading broadly, validate the requested outcome,
and use failures to guide the next intervention. Load domain guidance on demand.
Preserve unrelated changes and report actual checks and unresolved limitations.
Keep durable handoffs concise when continuity benefits. Measure efficiency with
comparable observed trials; do not claim savings from instruction changes alone.
