# Provenance and notices

AgentLean began from a privately supplied Codex Engineering Efficiency v2 workflow
pack and was developed into a domain-independent local toolkit. That historical
archive and the private development handoff are retained locally, excluded from
the public source bundle and package distributions. Public instructions and
runtime code are maintained in `agentlean/`.
